# 课题报告中已锁定的算法选型（必须包含、不可替换）

1. **NSA-Kalman**：噪声尺度自适应卡尔曼，观测噪声协方差 R 与检测置信度 s 负相关：
   `R_t = R_0 · (1 + (1 - s_t)^γ)`，使滤波器在低置信度时拒绝噪声观测、依赖先验。
2. **OC-SORT** (CVPR 2023)：观测中心范式，三阶段关联（IoU → OCM → 观测中心代价）。
3. **ORU（Observation-centric Re-Update）**：目标重现时，用 t_lost 与 t_reappear 两端观测**反向插值**生成虚拟轨迹，并用其重新校正卡尔曼协方差矩阵，避免遮挡期间线性外推漂移。
4. **OCM（Observation-Centric Momentum）**：用相邻观测差分计算瞬时速度方向，作为关联代价的方向项，解决"红绿灯弹射起步"滞后问题。
5. **IPM 单目物理重构**：用单应矩阵 H 把 bbox 底边中点（轮地接触点）映射为路面世界坐标 (X, Y)，进而计算物理速度。
