## 二、三模块输入/输出接口规范

> 建议用 `dataclass` / `TypedDict` 形式串联，与 Ultralytics `Results` 兼容。

### 2.1 模块 ① 分层感知（NMS-Free Detector）

#### 输入

```python
frame: np.ndarray  # shape (H, W, 3), BGR, uint8（或 RGB tensor）
frame_id: int
timestamp: float  # 单位 s
```

#### 输出

每帧 N 个检测框，end2end 已去重，无需 NMS：

```python
from __future__ import annotations


@dataclass
class Detections:
    frame_id: int
    timestamp: float
    bboxes: np.ndarray  # (N, 4)  xyxy, 像素坐标
    scores: np.ndarray  # (N,)    one-to-one 置信度
    cls: np.ndarray  # (N,)    类别 id（电动车=0）
    feats: np.ndarray | None  # (N, D)  可选 ReID/外观特征，给 Deep OC-SORT 用
```

> 当前 `model.predict(...)` 返回的 `Results.boxes` 已满足前 3 个字段；只需在 `inference_ebike.py` 加一层包装即可对外暴露统一结构。`feats` 后续做 Deep OC-SORT 时再补。

---

### 2.2 模块 ② 物理重构（Tracking + IPM）

> 把"非线性时空跟踪"和"图像→世界坐标"的物理映射合并在一起，因为两者都属于**物理一致性约束**，且跟踪需要在物理空间做速度/方向估计才稳定。

#### 输入

```python
detections_t: Detections  # 来自模块 ①，当前帧
H_ipm: np.ndarray  # (3, 3) 单应矩阵，标定一次性给出
track_state_prev: TrackPool  # 上一帧的轨迹池（卡尔曼状态）
```

#### 内部状态（轨迹池中每条 track）

```python
from __future__ import annotations


@dataclass
class TrackState:
    track_id: int
    # 图像空间（用于关联）
    bbox_img: np.ndarray  # (4,) xyxy
    kalman_mean: np.ndarray  # (8,)   [cx, cy, a, h, vx, vy, va, vh]
    kalman_cov: np.ndarray  # (8, 8)
    # 世界空间（用于认知）
    pos_world: np.ndarray  # (2,)   (X, Y) 单位 m
    vel_world: np.ndarray  # (2,)   (Vx, Vy) 单位 m/s
    heading: float  # rad，行驶方向
    # 历史
    history_img: list[np.ndarray]  # 最近 K 帧 bbox
    history_world: list[np.ndarray]  # 最近 K 帧 (X, Y)
    age: int
    hits: int
    time_since_update: int
    status: Literal[tentative, confirmed, lost]
```

#### 输出

每帧一份 `TrackedObjects`，喂给认知层：

```python
from __future__ import annotations


@dataclass
class TrackedObjects:
    frame_id: int
    timestamp: float
    tracks: list[TrackState]  # 仅 confirmed 的活跃轨迹
```

> **关键设计点**：模块 ② 必须同时输出**图像空间 bbox**（给可视化/取证截图）和**世界空间轨迹 (X, Y, V, θ)**（给规则推理）。`TopicReport (2).md` 中的 NSA-Kalman、ORU、OCM、IPM 全部在这层实现。

---

### 2.3 模块 ③ 认知推理（Trafficformer + LTN）

#### 输入

```python
@dataclass
class CognitionInput:
    tracked: TrackedObjects  # 来自模块 ②
    scene_context: SceneContext  # 场景静态/动态先验
```

```python
from __future__ import annotations


@dataclass
class SceneContext:
    # 静态：标定一次
    stopline_world: np.ndarray  # (2, 2) 停止线两端点 (X,Y)
    lane_polygons: dict[str, np.ndarray]  # 车道/非机动车道多边形
    forbidden_zones: dict[str, np.ndarray]  # 禁行区域
    # 动态：每帧更新
    traffic_light: Literal[red, yellow, green]
    weather: str | None
```

#### 内部张量化（喂给 LTN 的可微符号）

对每条轨迹，把感知/物理量映射为 `[0,1]` 的"模糊真值"：

```python
predicates = {
    "IsRedLight": p_red,  # scalar
    "CrossedLine": p_cross,  # 由 world 坐标判断
    "Speeding": sigmoid((v - v_th) / τ),
    "WrongWay": f(heading, lane_dir),
    "Intent_Avoid": trafficformer(history_world)["avoid"],  # ∈[0,1]
    # ...
}
```

#### 输出

结构化、可解释的违章记录：

```python
from __future__ import annotations


@dataclass
class Evidence:
    name: str  # 例如 "CrossedLine"
    value: float  # 真值 ∈ [0,1]
    raw: dict  # 关键原始数据：速度、坐标、阈值


@dataclass
class ViolationRecord:
    track_id: int
    frame_id: int
    timestamp: float
    violation_type: str  # "RunRedLight" / "WrongWay" / "Speeding"
    confidence: float  # LTN 满意度
    rule_expr: str  # 例如 "IsRedLight ∧ CrossedLine ∧ ¬Intent_Avoid"
    evidences: list[Evidence]  # 完整证据链
    snapshot_bbox: np.ndarray  # (4,) 取证截图框
    snapshot_path: str | None  # 关键帧落盘路径


@dataclass
class CognitionOutput:
    frame_id: int
    violations: list[ViolationRecord]
```

## 三、数据流总览

```
┌─────────────────────────┐   Detections        ┌────────────────────────────┐
│ ① 分层感知 (已实现)     │ ───────────────────▶ │ ② 物理重构 (待开发)        │
│ NMS-Free YOLOv11        │ bboxes/scores/cls   │ NSA-Kalman + OC-SORT + IPM │
│ 输入: frame (H,W,3)     │ (+ feats 可选)      │ 输入: Detections + H_ipm   │
└─────────────────────────┘                     └────────────────────────────┘
                                                            │ TrackedObjects
                                                            │ (含世界坐标/速度/方向)
                                                            ▼
                                                ┌────────────────────────────┐
                                                │ ③ 认知推理 (待开发)        │
                                                │ Trafficformer + LTN        │
                                                │ + SceneContext             │
                                                └────────────────────────────┘
                                                            │
                                                            ▼
                                                  list[ViolationRecord]
                                                  （含 rule_expr + evidences）
```

## 四、落地建议（最小改动启动模块 ②、③）

| 步骤                    | 内容                                                                                                                                             |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| **统一帧元数据**        | 在 `inference_ebike.py` 里把 `model.predict` 的 `Results` 包装成上面的 `Detections`，作为后续模块的标准入参，避免直接依赖 Ultralytics 的内部对象 |
| **`tracker/` 新目录**   | 放 NSA-Kalman、OC-SORT、ORU、OCM，对外只暴露 `Tracker.update(detections) -> TrackedObjects`                                                      |
| **`geometry/` 新目录**  | 放 `Homography` 类（加载/标定 `H_ipm`，提供 `img2world(pts)` / `world2img(pts)`），跟踪器内部调用，对外不需感知                                  |
| **`cognition/` 新目录** | 放 `IntentPredictor`（Trafficformer）和 `RuleEngine`（LTN），输入只依赖 `TrackedObjects + SceneContext`，输出 `ViolationRecord`                  |

### 关键解耦原则

- 感知层**绝不输出世界坐标**；
- 世界坐标在物理重构层生成；
- 认知层**只读** `world` 字段，不直接读图像 bbox（取证截图除外）。

这样三层可以独立替换 / 消融实验。
