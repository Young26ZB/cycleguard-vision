# 课题报告中已锁定的技术选型（必须包含、不可替换）

1. **Trafficformer 意图预测**：基于 Transformer 自注意力，输入轨迹历史窗口，输出未来 T 步轨迹分布 + 离散意图标签（直行 / 左转 / 右转 / 避让 / 掉头）。
2. **逆透视变换（IPM）已在模块 2 完成**：模块 3 直接消费世界坐标，不再做几何映射。
3. **逻辑张量网络（LTN）**：把交通法规一阶逻辑规则嵌入可微损失，使用 **Gödel t-norm** 算子（min/max 形式），与神经网络联合优化。
4. **结构化证据链输出**：每条违章必须包含 `rule_expr` 与逐项 `Evidence`，满足非现场执法的严谨性。

|------|---------|---------------------|
| IsRedLight | 直接读 SceneContext | sigmoid 退化为硬 {0,1} |
