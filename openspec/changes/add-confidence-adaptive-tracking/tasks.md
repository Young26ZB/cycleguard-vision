# Tasks

## 1. NSA 观测更新

- [ ] 1.1 确认前三项变更的实现和合成检查已可用。从现有真实更新路径接入受限的观测噪声缩放，记录开关与下限参数。用独立残差比较高低分框，并检查分数为 1 时的数值稳定性。
- [ ] 1.2 保持普通噪声与 ORU 虚拟噪声分离，实现真实更新的数值回退。用合成序列检查 NSA 关闭、虚拟观测、重现真框及数值失败路径，确认单次提交和回退计数。

## 2. 评估与本地联调

- [ ] 2.1 接入基线、全开和逐项关闭的评估配置，定义遮挡事件、匹配检测子集与质量门槛的登记方式。用有已知 ID 的合成序列验证恢复、错连、漏检和零分母统计。
- [ ] 2.2 对同一合成检测缓存执行组合对照和密集重现基准，记录 P50/P95/P99、吞吐、回退和内存。复查禁用全部增强时主链路输出可复现，报告标记本地合成范围。

## 3. 云端质量与实时性验收

- [ ] 3.2 用冻结配置在阿里云独立测试集完成配对消融，报告 IDF1、AssA、ID 切换及按遮挡时长分组的恢复和错连，区分全部重现及存在可匹配检测的事件。
- [ ] 3.3 在目标环境以原始视频和固定权重运行端到端验收，记录目标 FPS、预算、分位数、吞吐、掉帧、积压及各类回退。按质量与时延门槛选定配置，或记录尚无配置通过及其原因。
