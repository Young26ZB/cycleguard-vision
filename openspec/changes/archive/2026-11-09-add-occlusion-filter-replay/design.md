# Design

## Context

主链路产生预测状态，观测中心关联产生确定的一对一匹配和匹配来源。本变更使用 [OC-SORT](https://arxiv.org/html/2203.14360) 的 ORU 思路处理已重关联轨迹。触发条件是轨迹进入丢失状态后重新匹配，身份判定由前置关联完成。

## Goals / Non-Goals

- **Goals** 保留成功关联的 ID，并让重现帧得到完整回放后的状态或普通更新后的状态。
- **Non-Goals** 回放范围限于当前帧到达时已经发生的缺测区间，虚拟观测用于状态修复。真实物理路径、离线补帧和显式转弯模型另行研究。

## Decisions

1. **存一个快照。** 每条轨迹在一次成功的真实更新完成后替换快照，包含帧号、真实框、均值和协方差。只有开启 ORU 才维护这份状态。不存遮挡期间每次预测，避免随遮挡长度增长。
2. **回放与提交分离。** 保留本帧用于关联的常规预测。从快照复制临时状态，将两端框转换为同一 XYAH 测量坐标，依照帧号在中间帧线性插值。虚拟噪声用有正下限且不小于对应普通观测噪声的独立规则。逐帧预测与虚拟更新结束后，预测到当前帧并检查状态有限性、有效框与协方差数值性质。检查通过时选用回放预测，否则丢弃临时状态并选用常规预测。统一真实更新入口只对选中的预测融合当前实测，后续 NSA 复用此入口。
3. **用步数约束尖峰。** 配置单轨最大缺失帧数和单帧最大尝试步数。以缺失帧较少的轨迹优先、同长度按 ID 排序。先判断能否完整回放，超限当帧直接普通更新，无积压到下一帧的回放队列。回放中途失败也消耗已执行步数。相较于按墙钟临时停止，这个规则在不同设备上能重放相同路径。
4. **检查重现帧的尾部延迟。** 同一输入下测 ORU 开关，单列同步重现帧的 P95/P99 和整段统计，报告回放请求、成功、超限与数值回退。长遮挡沿用主链路的保留期，并允许设置更短的回放窗口。

## Risks / Trade-offs

- 多个虚拟点来自同一对端点，过高权重会虚假压缩协方差。采用保守噪声和短窗口，报告下一帧重关联和定位结果。
- 批量恢复会引起延迟尖峰。按整帧预算约束循环，超限用普通更新保留原匹配，不生成待处理回放任务。
- 两端点之间的弯道不可仅由端点唯一确定。虚拟轨迹保留在滤波器内部，不作为后续物理测量与证据。

## Migration Plan

默认沿用普通更新路径，开启 ORU 后再测量合成重现和真实片段。在重现成本超出预算时先收紧回放上限或关闭该增强，并保留对应配置供复现。
